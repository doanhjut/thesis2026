# IEEE journal manuscript

This directory contains the complete English master manuscript derived from the
thesis *A Multi-Stage Analysis Ransomware Detection System Integrating Active
Learning and XAI Fidelity Verification*.

## Manuscript files

- `main.tex`: IEEEtran master document (22 pages in a two-column surrogate
  build, including appendices and references).
- `sections/`: Introduction through Conclusion, followed by reproducibility and
  claim--evidence appendices.
- `figures/`: four figures generated by the verified experiment package.
- `references.bib`: 27 BibTeX records; 25 are cited in the manuscript.
- `CLAIM_EVIDENCE_MAP.csv`: reviewable mapping from each central claim to its
  artifact, status, and interpretation boundary.
- `PAPER_DEVELOPMENT_PLAN.md`: publication plan and remaining evidence gates.
- `phase1.tex`: archived preliminary draft retained for history.
- `releases/ransomware-paper-ieee-master.zip`: importable source archive for
  Overleaf or another IEEEtran-enabled LaTeX environment.

The author line includes Luu Van Doanh and supervisor/co-author Truong Ninh
Thuan. Institutional email addresses, ORCID identifiers, author order,
corresponding-author status, and final authorship consent must be confirmed
before submission.

## Build

Upload the master ZIP to Overleaf and compile `main.tex` with pdfLaTeX and
BibTeX, or run:

```sh
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

The local environment used for this update did not contain `IEEEtran.cls` or
`IEEEtran.bst`. Syntax, citations, references, layout overflow, and page extent
were therefore checked with a temporary two-column `article`/`ieeetr` surrogate;
that validation produced 22 pages with no unresolved citations, unresolved
references, or overfull boxes. The release ZIP retains the required IEEEtran
source and must receive a final journal-template build before submission.

## Evidence policy

All numerical claims trace to `results/measured_20261014/`. The active-learning
and fidelity experiments are computationally verified within the documented
row-disjoint pilot. Upstream data provenance and ransomware-specific label
semantics remain unverified. PID fusion is fully specified as a method and
evaluation protocol, but it has no aligned observed dynamic signal; the paper
therefore reports no PID performance or end-to-end latency result. It does not
report an aggregate OFS.
