# IEEE paper project

This directory contains the English journal manuscript derived from the thesis
"A Multi-Stage Analysis Ransomware Detection System Integrating Active Learning
and XAI Fidelity Verification."

## Files

- `phase1.tex`: Phase 1 manuscript source (title, abstract, keywords,
  Introduction, and Related Work).
- `references.bib`: bibliography placeholder to be completed in Phase 4.
- `releases/ransomware-paper-ieee-phase1.zip`: importable Overleaf/LaTeX project.

The ZIP exposes `phase1.tex` as `main.tex`, so it can be uploaded directly as a
new Overleaf project. The LaTeX environment must provide the standard
`IEEEtran` class. Bibliographic entries and the final bibliography commands are
reserved for Phase 4.

## Evidence policy

Claims must trace to `results/measured_20261014/`. Active Learning and Fidelity
are verified within the documented row-disjoint pilot. PID fusion remains a
proposed component pending aligned, independently observed dynamic evidence.
Do not report an aggregate OFS until a validated normalization and weighting
rule exists.
